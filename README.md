# head-md-play-to-prevention
Play To Prevention is an Innosuisse-funded research project developed in collaboration with the [Master Media Design](https://head.hesge.ch/en/programs-research/master-arts-media-design) at [HEAD – Genève](https://head.hesge.ch) ([HES-SO](https://hesge.ch)) and [Arpège](https://arpegespt.ch).

## Research
We are currently at the research phase of the project. During this phase, we will be investigating various documents related to cyberbullying.

## Echo (student project)
Echo is a choice-driven narrative game about cyberbullying, for ages 12–16, by Lorie Crettex and Nouria Da Ros.
- Pitch: [process/2026-11-17](process/2026-11-17/readme.md)
- Play online: <https://lolocret.github.io/head-md-play-to-prevention/code/> (the computer shows a QR code, the phone scans it and becomes the remote)
- Play locally: run `npm start` in this folder, then open the address it prints (`npm run tunnel` also makes the phone work from any network)
- Playable prototype: [code](code/)
