# 2026-10-05 — Starting research

Aujourd'hui, nous avons commencé à utiliser Markdown comme méthode de prise de notes.

## Méthodologie
La méthode vient de [Pippin Barr](https://pippinbarr.com/), qui a documenté tout le processus de création de son jeu [It Is As If You Were Doing Work](https://pippinbarr.com/itisasifyouweredoingwork/) directement sur GitHub, avec seulement du Markdown, des dossiers, des images et du code, plutôt que sous forme de blog.
